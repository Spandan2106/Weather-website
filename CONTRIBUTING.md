# 🤝 Contributing to Weather App

Thank you for considering contributing to the Weather App! Contributions are what make the open-source community such an amazing place to learn, inspire, and create. Any contributions you make are **greatly appreciated**.

---

## 📜 Code of Conduct

Please help us keep this project open, inclusive, and welcoming. Be respectful, supportive, and collaborative in all discussions and code reviews.

---

## 🛠️ How Can You Contribute?

### 1. Reporting Bugs
Found a bug or an issue with the app?
* Open an **[Issue](https://github.com/Spandan2106/Weather-website/issues)** on GitHub.
* Clearly describe the issue, steps to reproduce it, and expected vs. actual behavior.
* Include screenshots or error messages if applicable.

### 2. Suggesting Enhancements
Have an idea for a new feature or design improvement?
* Open an issue with the tag `enhancement`.
* Explain why this feature would be useful and how it should work.

### 3. Submitting Code Changes

Follow these steps to contribute code directly:

#### Step 1: Fork the Repository
Click the **Fork** button at the top right of the project page to create your own copy of the repository.
